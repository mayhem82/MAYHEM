About this daily estimate

NOAA estimated global atmospheric CO2 trend, based on four baseline observatories. The seasonally adjusted trend is in parts per million, not an instantaneous direct global measurement, and is not integrated into emitted tonnes.

Fetches the official CSV on Start, manually, and hourly while open after the first request. Failed checks retain a clearly dated locally cached snapshot. No new observation is implied by an unchanged successful check. NOAA can revise estimates. There is no guaranteed update schedule. Source-file update time is unavailable in this prototype.

How this counter works +

From an annual rate to your moment

Estimate = published annual amount × active seconds ÷ 31,536,000 (365 days). Approximately signs and rounded displays reflect estimates, not precise observations.

A constant rate smooths seasonal and geographic variation. A displayed fraction is a mathematical estimate; it does not identify a real event occurring now.

Accumulation and trend are different

An accumulating total describes a flow over your selected time. A trend compares published periods and can improve, worsen, stay stable or be mixed. Indicators are never added together or converted into an overall score.

Country views

World and each country use the same active time, with independent amounts. Switching views never resets the timer or adds elapsed time twice. Country estimates use only that country's reported rates and dates; unavailable data is never zero or a population/GDP allocation. Metric scope is shown explicitly. NOAA atmospheric CO2 concentration remains global and is hidden in country views.

Your timer

The screen updates every second. Pause excludes time until Resume. A background tab continues counting when running, using elapsed timestamps rather than counting screen refreshes. Reset stops the timer and clears your moment. Reloading starts a new session. Device sleep handling can vary by browser.

Sources, refresh and rate changes

Source publication dates and data reference periods are shown per indicator. The last successful check means the local bundled JSON passed validation, even if unchanged. It does not mean the official source published new data. Polling checks this file every 5 minutes while the page is open; hidden tabs may throttle checks. Returning to the tab triggers a check if due.

Failed checks retain the last validated dataset and show an error. New rates apply only to future active seconds; amounts already accumulated retain their previous rate. Source details show the current rate. If data arrives after Start, estimates exclude the earlier period with no validated rate. Reset begins a fresh moment with current rates.
